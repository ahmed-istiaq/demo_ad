## Brand & Style

This design system delivers a high-density, authoritative dark-mode workspace built for medical academics, clinical researchers, and MBBS students. Merging the austere rigor of clinical informatics with high-tech cyber-repository aesthetics, the interface communicates immediate catalog utility, live telemetry, and frictionless access to high-yield clinical literature.

### Aesthetic Paradigm: Medical Cyber-Grid & Precision Glass
The visual style operates at the intersection of modern deep-navy glassmorphism and surgical dashboard ergonomics. It pairs near-black canvas surfaces with luminous spectral accents (biomedical cyan and neural emerald), subtle translucent backdrops, micro-thin borderline luminescence, and monospaced catalog markers. The mood is analytical, intellectual, hyper-curated, and immediate—eliminating decorative clutter in favor of high-yield data visibility, structured category navigation, and tactical status badges.

## Colors

The palette establishes an ultra-deep spectral hierarchy suited for long hours of intense clinical study while eliminating visual fatigue.

- **Primary (`#00D2FF` / Electric Cyan):** The primary kinetic signal. Reserved for active filters, focal headlines, primary action triggers, search field glow, and live indexing markers.
- **Secondary (`#10B981` / Biomedical Emerald):** Represents live health status, cloud-sync confirmation, valid repository indices, and positive clinical actions.
- **Tertiary (`#F59E0B` / Amber Cadmium):** Highlights high-yield clinical pearls, board-priority tags, system advisories, and sponsored study inserts.
- **Neutral (`#0A0F1D` / Deep Navy Charcoal):** The underlying foundation that anchors deep spatial perception across multi-layered card stacks and backdrops.

### Surface System
Surfaces leverage layered luminescence: `surface-base` (`#030712`) establishes the deepest canvas layer; `surface-canvas` (`#0A0F1D`) forms primary section containers; `surface-card` (`#0D1527`) frames modular resource items; and `surface-overlay` (`#162038`) handles elevated modals, active search popovers, and floating pill chips.

## Typography

The typographic system utilizes a disciplined dual-engine structure: **Inter** handles narrative clarity, headlines, and dense UI controls, while **JetBrains Mono** provides tactical terminal precision for database metadata, shelf indexing codes, sync timestamps, and repository metrics.

Headings leverage tight tracking and high-contrast weights to impose clear hierarchy over catalog collections. Monospaced tokens are uppercase-optimized to mimic analytical instrumentation displays.

## Layout & Spacing

The layout adopts a modular 12-column responsive fluid grid structured for scanning large datasets and horizontal card carousels.

- **Desktop (>= 1280px):** 12-column configuration, 40px outer container padding, 20px gutters. Content reaches a maximum reading width of 1440px.
- **Tablet (768px – 1279px):** 8-column layout, 24px margins, 16px gutters. Resource shelves gracefully collapse to 2-column or horizontal snap-scrolling ribbons.
- **Mobile (< 768px):** 4-column layout, 16px margins, 12px gutters. Category chip bands convert into sticky x-axis momentum scrolls.

The vertical rhythm is anchored around an 8px baseline rhythm (`space-xs` = 4px, `space-sm` = 8px, `space-md` = 16px, `space-lg` = 24px, `space-xl` = 40px), guaranteeing systematic vertical pacing between shelf headers, filter strips, and data blocks.

## Elevation & Depth

Spatial separation avoids conventional opaque, heavy drop shadows, instead using **spectral edge luminescence** and **frosted backdrop blur**.

### Tonal Stratification
1. **Level 0 (Background):** Solid `#030712` to `#0A0F1D` canvas background, accented by faint radial ambient meshes in `#00D2FF` (opacity: 0.05).
2. **Level 1 (Card & Module Surfaces):** Semi-transparent `#0D1527` with 12px backdrop blur (`backdrop-filter: blur(12px)`), bound by a 1px composite outline (`rgba(56, 189, 248, 0.12)`).
3. **Level 2 (Interactive Elements & Drawers):** `#162038` with 1px border (`rgba(0, 210, 255, 0.35)`) and a diffused cyan glow: `box-shadow: 0 0 20px -5px rgba(0, 210, 255, 0.25)`.
4. **Level 3 (Modals & Search Autocomplete):** High-density glass `#0D1527` (opacity: 0.95), 24px blur, crisp `#00D2FF` perimeter halo, and depth shadow `0 24px 48px -12px rgba(0, 0, 0, 0.8)`.

## Shapes

The geometric architecture combines structural rectilinear discipline with polished micro-radii to echo cleanroom hardware terminals.

- **Standard Containers & Cards:** Set at `roundedness: 2` (8px border-radius, scaling to 16px for larger card panels) to offer smooth corners without appearing juvenile.
- **Pill Badges & Status Indicators:** Set to fully rounded circular pill caps (`border-radius: 9999px`) for high visual contrast against rectilinear cards.
- **Action Buttons & Inputs:** Uniform 8px to 10px corner rounding for tactile clarity.
- **Media Thumbnails:** Consistent 8px inner radiused clipping masks with dark overlay vignettes.

## Components

### 1. Global Search & Command Bar
- Input field housed inside an obsidian pill box (`#0D1527` at 80% opacity, border `rgba(56, 189, 248, 0.2)`).
- Left-aligned cyan search glyph, right-aligned terminal keyboard badge (e.g. `⌘K` or `Ctrl+K` in `JetBrains Mono`).
- Focus state triggers an expanding soft cyan perimeter aura (`box-shadow: 0 0 16px rgba(0, 210, 255, 0.3)`) and sharpens the border to `#00D2FF`.

### 2. Category & Filter Chips
- **Idle State:** Capsule-shaped (`9999px`), surface `#0D1527`, thin line border `rgba(255,255,255,0.08)`, typography in `label-pill`, color `#94A3B8`. Includes an inner numerical counter badge in `JetBrains Mono`.
- **Selected State:** Saturated primary surface `#00D2FF` with `#030712` high-contrast typography, or deep navy fill with a brilliant `#00D2FF` border and illuminated ambient glow.

### 3. Clinical Resource Cards
- Top section holds a high-resolution 16:9 thumbnail preview, capped by floating category pills (e.g., `Anatomy`, `Thorax`, `High-Yield`) with dark frosted backgrounds.
- Card body features an Inter semi-bold title, a two-line muted summary, and an explicit metadata footer rendered in `JetBrains Mono` (`Complete PDF Atlas`, `Slide Set`, file weight).
- Bottom action bar houses dual triggers: a secondary outline download button and an electric-accented Telegram external dispatch link with directional arrow icons.
- Hover transition lifts the card 4px vertically with an intensified perimeter glow (`border-color: #00D2FF`).

### 4. Interactive Metric Counters
- Rectangular modular tiles featuring a double-layer vertical layout.
- Metric readout in large `mono-counter` (`#00D2FF` or `#10B981`), accented by a live status micro-beacon (pulsing 6px dot).
- Subtitle in uppercase `label-meta` (`#94A3B8`) providing verified repository indices (`40+ Blueprints`, `20+ Volumes`).

### 5. Display Ads & Sponsored Clinical Resource Slots
- **Sponsored Study Resource Cards:** Match standard resource card anatomy but feature an amber caution badge (`label-meta`: `SPONSORED` / `MBBS PARTNER`) using `#F59E0B`. Distinctive inner border using a low-opacity amber gradient (`rgba(245, 158, 11, 0.25)`).
- **Banner Ad Containers:** Clean, fixed-dimension utility frames (leaderboard `728x90` and sidebar `300x250`) surrounded by a subtle dotted technical border (`border: 1px dashed rgba(255,255,255,0.15)`), labeled with `label-meta` text `"ADVERTISEMENT // VERIFIED CLINICAL SPONSOR"` to maintain transparency and aesthetic rigor.

### 6. Buttons & Control Badges
- **Primary Action (Join/Download):** Solid gradient fill from `#00D2FF` to `#00A3FF`, text `#030712`, weight 600.
- **Channel Action (Telegram Live Feed):** Deep sapphire tint (`#0D1527`), border `rgba(34, 158, 217, 0.4)`, text `#38BDF8`, displaying dynamic active indicator dots.
